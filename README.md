
# Python to Data Engineering

My personal Python learning repository, documenting concepts, exercises, and practical experiments from my previous lessons to my future goal of becoming a Data Engineer.

## About This Repository

This repository contains my previous Python learning materials, including exercises from different courses and resources. It covers fundamental programming concepts, object-oriented programming, algorithms, data structures, testing, file handling, regular expressions, and working with data and networks.

My goal is to consolidate this knowledge and progressively apply Python to Data Engineering.
